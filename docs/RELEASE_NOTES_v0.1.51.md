# DSTS RU v0.1.51

Этот выпуск закрывает ошибки из GitHub issue #2 и одновременно расширяет
редакторский проход на похожие места.

Исправлены опечатка «глубина резкоЗти», остатки `SP` в описаниях предметов,
неестественное «Изучен Уровень», название атаки Коромона «Пузыри» и имя Пико
Девимона в его профиле. Заодно унифицированы обозначения `ОЗ`, `ОС` и `КО`,
переписаны буквальные формулировки обучения и проверены соседние интерфейсные
строки.

По английскому оригиналу полностью вычитаны 55 профилей дигимонов. Исправлены
машинные конструкции, грамматика, имена форм и названия приёмов — в том числе
Слейпмон, Фанбимон, ПлатинаНумемон, Гэнкумон, Бакэмон, Мугендрамон, Химерамон
и Вайзмон. Все найденные в профилях названия атак сверены с игровой таблицей
навыков.

Отдельно устранена причина, по которой часть уже исправленных фраз могла
оставаться старой в истории диалогов или другом экране. Теперь полный
`app_text01` получает 258 адресных замен, а сборка проверяет структуру и
нетронутые данные всех 213 его таблиц до и после упаковки. Если исходные файлы
игры отличаются от проверенной версии, оверлей прекращает работу без частичной
записи.

Для установки используйте `DSTS_RU_Installer_v0.1.51.exe`. Установщик рассчитан
на Steam build 23514637 и сохраняет резервные копии заменяемых файлов. Версия
перевода отображается в левом нижнем углу главного меню.
