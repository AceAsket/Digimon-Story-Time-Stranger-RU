## Что подтверждено в Lua

- `patch/lua/function_common.lua` содержит `GetGender()`. Он читает `Common.GetPlayerModelName()`: модель `pc001` даёт `HERO`, модель `pc002` — `HEROINE`.
- В том же файле `PlayPartVoice("operator", ...)` уже инвертирует голос: для `HERO` выбирается `pcf001`, для `HEROINE` — `pcm001`. То есть правило «мужчина → женский Оператор и наоборот» уже есть в игре для озвучки.
- Общие обёртки `Message`, `MessageAuto`, `MessageTalk`, `MessageTalkAuto`, `MessageTalkSel` в `function_common.lua` проходят перед вызовом `Talk.*`; аналогичные вспомогательные вызовы есть в `function_field.lua`.
- Декомпиляция Lua выявила 6 прямых исключений `Talk.Message*`: `battle_11200010.lua`, `m360.lua` (3), `m440.lua`, `t04prcs.lua`. Дополнительная проверка production-ID нашла отдельный вызов `Battle.MessageTalk(1081020022)` в `battle_10810200.lua`; он также включён в патч.
- Машиночитаемый список этих мест сохранён в `exports/lua_direct_talk_audit_v064.csv`.
- В MBE нет найденного макроса рода. Суффиксы `_M`/`_F` в четвёртом поле строк — существующие алиасы голоса/события, а не две автоматически выбираемые русские текстовые строки.

## Рабочая схема

1. Для прямой реплики с формой рода создать две строки MBE, например `id__H` и `id__F`, сохранив управляющие теги и алиасы голоса. Для `MessageTalkSel` движок получает только первый ID трёхстрочной группы, поэтому технически дублируется вся группа, но текст меняется только у подтверждённой родовой строки.
2. В таблице Lua хранить `base_id -> {hero = id__H, heroine = id__F}`. Для реплик игрока `hero` — мужской текст, `heroine` — женский; для Оператора значения намеренно перевёрнуты.
3. В общих пяти обёртках передавать в `Talk.*` результат `ResolveGenderedMessageId(id)`. Семь обходных вызовов также заменить на этот resolver.
4. Для строк без форм рода resolver возвращает исходный ID, поэтому динамическая таблица может быть неполной и расширяться по мере аудита.

Это минимальный и безопасный путь: Lua уже знает выбор героя, а текстовые варианты остаются обычными локализованными MBE-строками. Один только CSV не может выбрать форму во время игры.
