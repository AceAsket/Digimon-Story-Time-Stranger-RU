# DSTS RU v0.1.49

Главное изменение — исправлен ввод кириллицы в имени героя. PC-версия
ошибочно принимала байты CP1251 за Unicode, поэтому русские буквы превращались
в `à/ä/ï`. Установщик добавляет в корень игры проверенный x64-модуль
`dinput8.dll`, который исправляет только ввод символов и передаёт системный
DirectInput без изменений.

Также полностью вычитана таблица прохожих и полицейских Синдзюку. Исправлены
35 буквальных и механических формулировок про остановившиеся поезда, отменённую
работу, блокпосты, протест и электромагнитную сеть. Английское `big/large
tremor` теперь недвусмысленно переведено как «сильный подземный толчок».

Установка и восстановление обновлены с учётом нативного модуля. Если в папке
игры уже есть сторонний `dinput8.dll`, установщик остановится до замены файлов и
не повредит другой мод. Добавленный переводом DLL удаляется при восстановлении
бэкапа.

Для установки используйте `DSTS_RU_Installer_v0.1.49.exe`. Старые установщики
при проверке обновлений загрузят новый EXE, а установщик 0.1.49 и новее сможет
использовать компактный `DSTS_RU_Update_v0.1.49.zip`.

Уже сохранённое испорченное имя автоматически не меняется. После установки
введите его заново через пункт игры «Изменить имя» либо проверьте исправление в
новом прохождении.

Исправление ввода проверено при русской системной кодовой странице Windows
(CP1251). Экспериментальный режим UTF-8 и другие ANSI-кодовые страницы пока не
поддерживаются гарантированно.
