# DSTS RU v0.1.52

Этот выпуск завершает полную редакторскую вычитку русского текста игры.
Исправлены опечатки, пунктуация, согласование, неестественные машинные
формулировки и разнобой терминов в интерфейсе, обучении, предметах, навыках,
основном сюжете, дополнительных заданиях, репликах NPC, чатах, профилях
дигимонов и DLC.

Отдельно заново проверены обращения к герою и связка с Оператором. Для мужского
персонажа используются женские формы речи Оператора, для женского персонажа —
мужские. В динамическую карту вошли 118 подтверждённых реплик и 268 технических
вариантов мужского и женского рода; все 174 найденных обращения к герою покрыты
проверкой.

Полный `app_text01` теперь получает 4655 адресных замен: 4628 общих и ещё 27
специальных для этого архива. Перед упаковкой сборка проверяет структуру и
нетронутые данные всех 213 таблиц, а после упаковки — содержимое обоих игровых
архивов, Lua-хуки и нативную библиотеку ввода.

Для установки используйте `DSTS_RU_Installer_v0.1.52.exe`. Установщик рассчитан
на Steam build 23514637 и сохраняет резервные копии заменяемых файлов. Версия
перевода отображается в левом нижнем углу главного меню.
