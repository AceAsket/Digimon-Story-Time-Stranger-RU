# Расшифровка режимов дигимонов

В игровых строках некоторые формы записаны сокращениями. В русском переводе сокращения раскрываются в название режима.

| Сокращение | Английская форма | Русский вариант |
| --- | --- | --- |
| BM | Burst Mode | Взрывной режим |
| BM | Blast Mode, только для Beelzemon/Beelzebumon | Бласт-режим |
| CM | Crimson Mode | Багровый режим |
| DM | Destroy Mode | Режим разрушения |
| DM | Deisui Mode, только для Bacchusmon | Режим опьянения |
| FM | Fighter Mode | Режим бойца |
| HM | Holy Mode | Священный режим |
| HM | Hysteric Mode, только для Junomon | Истерический режим |
| LM | Leopard Mode | Режим леопарда |
| PM | Paladin Mode | Режим паладина |
| RM | Rage Mode | Режим ярости |
| SM | Sleep Mode | Режим сна |
| SM | Satan Mode, только для Lucemon | Режим Сатаны |
| WM | Wrath Mode | Режим гнева |
