# Установщик Digimon Story Time Stranger RU

## Быстрый запуск

1. Распакуйте архив установщика.
2. Запустите `DSTS-RU-Installer.exe`.
3. Выберите папку игры через `Обзор...`, если установщик не нашёл её автоматически.
4. Нажмите `Установить перевод`.

## Что делает установщик

- ищет `app_text01.dx11.mvgl` и `patch_text01.dx11.mvgl` внутри папки игры;
- сохраняет оригиналы в `_dsts_ru_backups/<дата-время>`;
- копирует файлы из `payload`;
- пишет `manifest.json` в папку бэкапа.

## Восстановление

В `DSTS-RU-Installer.exe` выберите папку игры и нажмите `Восстановить бэкап`.

`install.cmd` и `restore-backup.cmd` оставлены как запасной консольный вариант.
