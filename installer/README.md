# Установщик Digimon Story Time Stranger RU

## Быстрый запуск

### Один файл

1. Запустите `DSTS_RU_Installer_v*.exe`.
2. Выберите папку игры через `Обзор...`, если установщик не нашёл её автоматически.
3. Нажмите `Установить перевод`.

### ZIP-архив

1. Распакуйте архив установщика.
2. Запустите `DSTS-RU-Installer.exe`.
3. Выберите папку игры через `Обзор...`, если установщик не нашёл её автоматически.
4. Нажмите `Установить перевод`.

> **Важно:** «История диалогов» хранит в сохранении текст уже показанных реплик.
> Установка или обновление перевода не меняет старые записи; новые и повторно
> показанные реплики отображаются в актуальной редакции.

## Что делает установщик

- ищет `app_text01.dx11.mvgl` и `patch_text01.dx11.mvgl` внутри папки игры;
- сохраняет оригиналы в `_dsts_ru_backups/<дата-время>`;
- копирует файлы из встроенного payload или из папки `payload` рядом с ZIP-версией;
- устанавливает в корень игры `dinput8.dll`, исправляющий ввод кириллицы в имени героя;
- пишет `manifest.json` в папку бэкапа.

Исправление ввода проверено при русской системной кодовой странице Windows
(CP1251). Экспериментальный режим UTF-8 и другие ANSI-кодовые страницы пока не
поддерживаются гарантированно.

Если в корне игры уже находится сторонний `dinput8.dll`, установка прерывается до
замены каких-либо файлов. Это защищает другие моды от перезаписи. Удалите такой
мод его штатным способом либо восстановите его оригинальный загрузчик, затем
повторите установку.

## Восстановление

В `DSTS-RU-Installer.exe` выберите папку игры и нажмите `Восстановить бэкап`.
Добавленный переводом `dinput8.dll` при этом удаляется; существовавший до
установки файл восстанавливается из резервной копии.

`install.cmd` и `restore-backup.cmd` оставлены как запасной консольный вариант.
