## Как разбирать

1. Сначала P1: кодировка, HP/SP, точные кальки, явное рассогласование и пунктуация.
2. Затем P2: сверять `source_en`, `previous_ru` и `next_ru`; исправлять только подтверждённые случаи.
3. Сначала проверить `identifier_collision`, затем `same_ru_different_en` на потерю характера и оттенков.
4. `repeated_ngram` использовать только для выборки: совпадение само по себе не является ошибкой.
5. Не заменять массово «действительно», «довольно», «данный» и местоимения без контекста.
