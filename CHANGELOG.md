# Changelog

## 0.1.11 - 2026-06-26

- Добавлены опциональные DLC-архивы `addcont_*_text01.dx11.mvgl` в payload установщика.
- Переведены тексты Undub для дополнительных эпизодов 01-03, предметных DLC 05/07/12 и чата/профилей DLC 17.
- Установщик теперь ставит DLC-файлы только если они найдены в папке игры, не прерывая установку при отсутствии отдельных DLC.
- Пересобран EXE/ZIP-инсталлятор с полным набором основных и DLC-текстов.
